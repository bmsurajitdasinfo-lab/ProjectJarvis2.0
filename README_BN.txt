PROJECT JARVIS 2.0 — Starter App (v0.1)

এই প্রথম সংস্করণে:
- Android অ্যাপের প্রাথমিক স্ক্রিন
- বোতাম চেপে বাংলা Speech Recognition
- শনাক্ত করা কথাটি স্ক্রিনে দেখানো
- বাংলা Text-to-Speech দিয়ে উত্তর

এখনও যা নেই:
- AI brain / online API connection
- offline language model
- “Hey JARVIS” always-listening wake word
- lock-screen hotword
- calls, SMS, WhatsApp automation
- GK/Math solving engine

তৈরি ও চালানোর ধাপ:
1. Windows-এ Android Studio ইনস্টল করুন।
2. ZIP ফাইল Extract করুন।
3. Android Studio > Open > Project_JARVIS_2_0 ফোল্ডার নির্বাচন করুন।
4. Gradle Sync শেষ হতে দিন।
5. ফোনে Developer options ও USB debugging চালু করে USB দিয়ে যুক্ত করুন।
6. Android Studio-তে Run চাপুন।
7. প্রথমবার Microphone permission Allow করুন।

নোট:
Speech recognition ফোনের উপলব্ধ recognition service-এর উপর নির্ভর করে এবং সাধারণত ইন্টারনেট লাগতে পারে।
এটি একটি starter scaffold; production-ready বা সম্পূর্ণ JARVIS নয়।
